状态按“已可用、正在完善、暂未提供”的顺序排列。知意测试档和下一轮桌面发行不会被写进正式背诵档的功能承诺。

正式背诵档当前可用

以下能力属于当前正式背诵档；不需要账号，也不以云端服务作为练习前提。

已可用
课文与阅读入口可浏览 148 篇初中与高中课文；课文详情保留“译与赏”和全文赏析的只读阅读入口。
文言知识工具可单独浏览 1,152 条实词/虚词和 29 条基础句式；它们是阅读工具，不计入背诵掌握度。
逐字背诵可用键盘完成翻开、提示、标错、撤销与确认；错误和提示保留到具体位置。
记忆支点系统只给少量起步提示，并随复习成功逐步减少，最后回到独立回忆。
复习、计划与预测到期复习、新内容和每日时间预算分别处理；计划页会说明今天的队列和预计负荷。
状态回滚与来源记录复习前后状态、入队理由和内容来源分别留档；撤销会恢复已有状态，而不是重新猜测。

正在完善与验证

已有数据结构或页面入口，但仍需要内容复核、真实设备验证或完整流程验证。

正在完善
内容复核与读音校正课文、句读、注释和读音仍按篇复核；候选、机器校对和人工确认会保持分开，不把“可浏览”写成教材审定。
新手教程练习沙盒和真实学习记录已隔离，完整的新手流程仍在补齐。
桌面发行知意测试版 v2.5.0 已提供 macOS 与 Windows x64 安装包；代码签名与跨设备验收状态以下载页与 Release 为准。

暂未提供给正式背诵档

这些功能没有被隐藏成“待解锁”入口；目前就是不提供，避免对使用预期造成误导。

暂未提供
账号、云同步与自动备份学习记录只保存在当前设备；重装、清理应用数据或更换电脑前，需要自行保留重要记录。
自动更新与完整签名流程当前没有自动更新渠道；不同平台的安装、签名和验收状态会在下载页单独说明。
语音识别与朗读判定目前不采集朗读音频，也不会根据朗读自动判对错。
理解答题与逐句翻译这些能力保留在“知意”独立测试档，不属于正式背诵档，也不能从正式档通过链接或设置打开。
AI 学习对话与通用自动判分当前没有面向所有用户开放的 AI 学习服务；任何后续能力都必须先限定内容依据、反馈范围和数据边界。

开发日志

已记录的结构更新，按时间倒序。

日期取自对应迁移文件；每条记录描述已经发生的结构调整。

2026-08-09#013

理解练习按段落解锁，翻译评分留在服务端

深入学习不再等待整篇背完：段落完成首次成功提取且不在重新学习状态后，才解锁关联练习。翻译题的参考译文和评分点不发送到浏览器。

  • 新增 deep_translation_tasks 与 deep_translation_attempts，保存题目、作答和评分结果
  • 参考译文、评分点和可选 AI 凭据只保留在本机服务端
  • 未配置受保护 AI 时明确使用本机参考评分
2026-08-09#012

学习计划保存教材范围与内容就绪状态

同一篇作品在不同教材目录中的位置和节选范围不能只靠篇目 ID 推断。新计划保存当时选择的范围，避免后续内容修改悄悄扩大任务。

  • 学习计划保存目录入口、全文或节选模式与精确段落范围
  • 旧计划保留兼容说明，不把空范围静默解释为新的教材范围
  • 内容接口区分背诵、拼音和理解训练的就绪状态
2026-08-09#011

建立独立的理解练习轨道

实词、虚词和句式练习复用通用记忆状态，但不进入字符遥测。题目必须锚定到具体篇目、段落和知识位置。

  • 新增理解练习配置、记忆项与作答记录
  • 题目锚点与义项通过数据库约束校验，避免跨段落错配
  • 理解练习的每日预算与背诵记录保持分离
2026-08-09#010

为同一字词的不同语境建立义项表

一个词条可以对应多个义项，但正式练习必须指向具体位置的一个已审核义项，避免把孤立词典义当作题目答案。

  • 新增 content_knowledge_senses，保存义项、词性、来源与审核状态
  • 知识链接可关联稳定义项 ID，保留旧提示的兼容入口
  • 内容状态和来源信息随义项保存，供后续审校使用
2026-08-09#009

把每日新内容基准与临时上限分开

正常学习日的投放目标和异常情况下的安全上限不是同一个数。排程据此在到期复习压力较高时收缩新内容。

  • 学习计划新增 new_content_baseline
  • 保留既有计划的原有意图，不用新默认值覆盖历史设置
  • 每日队列继续优先处理到期复习
2026-08-06#008

教程沙盒与计划开关

新手教程需要一块可以随便写坏的地方。沙盒与真实的记忆条目、复习日志、学习计划完全隔离，重置多少次都不会污染个人模型。

  • 新增 tutorial_sandboxes，教程状态独立存放、可整块丢弃
  • 沙盒记录不参与 FSRS 状态更新，不进入任何统计
  • 学习计划新增启用与暂停控制
2026-08-02#007

排程 v0.2：到期与新学之间划一条硬边界

旧版会让新内容挤掉今天该复习的句子。v0.2 把「到期复习」和「学习新内容」分成两个不可互相侵占的额度，每日节奏改由当前学习计划的截止日推算。

  • 优先级算法升级为 lnk-priority-v0.2
  • 到期召回与新材料使用各自独立的名额
  • 每一条每日计划项都会快照生成它的理由，事后可复查
2026-08-01#006

学习计划

长期目标和当天队列是两件事。学习计划描述「到某个日期前背完哪些篇目」，每日计划才是被生成出来的执行队列。同一时刻只允许一份计划驱动排程。

  • 新增 learning_plans 与 learning_plan_works
  • 截止日期进入排程权重，成为可解释的排序因素
  • 历史计划保留，但不会同时生效
2026-08-01#005

内容质检与「机器校对不等于已审」

自动比对结果单独建表，刻意不与发布状态混在一起。机器说文本对得上，不代表有人真的读过并认可它。

  • 新增 content_qa_results，记录来源比对状态
  • machine_verified / contains_match / mismatch / unresolved 四态分离
  • 发布仍然需要人工确认，机器结果只作为线索
2026-07-31#004

课程目录与知识点

同一篇作品可能同时出现在必背目录和不同版本的教材里，但正文只应该有一份。目录与作品做成多对多，正文保持唯一。

  • 新增 content_catalogs 与 catalog_work_entries
  • 新增 content_knowledge_items 与 content_knowledge_links
  • 新增 pronunciation_overrides，处理古音与破读
2026-07-31#003

逐字注释

卡住的往往不是整句，是其中一个字。字级注释挂在具体的 token 上，并记录它的出处与来源类型。

  • 新增 character_glosses，注释精确到字的位置
  • 每条注释带 source_label 与 source_uri
  • provenance 区分编辑撰写与外部引用
2026-07-31#002

复习可回滚

手滑按错一次，不应该让一段记忆的排程从此偏掉。复习前后的完整状态与引擎日志一并留存，撤销是有据可依的还原。

  • review_logs 记录 item_before_json 与 item_after_json
  • 保留 engine_log_json，可复现当次调度决策
  • 撤销恢复的是状态本身，不是重新猜一个值
2026-07-30#001

四层地基

第一版迁移一次性把内容、记忆、排程、交互四层的表结构立起来，此后所有改动都在这个分层上加，没有推倒重来。

  • 内容层：works、segments、knowledge_entries
  • 记忆层：memory_items、review_sessions、review_logs
  • 排程层：scheduler_configs、daily_plans、daily_plan_items
  • 交互层：hint_events、interaction_events、token_stats
能力路线

从“背得住”，逐步走向“读得懂”。

这是能力方向图，不含发布日期。当前正式背诵档在最前；受控测试与后续方向依次列在后面。

  1. V1Shixi · 时习正式背诵档

    能背、能复习、能形成记忆计划。

    当前重点是背诵、复习、计划、预测和只读知识工具；理解答题、翻译和鉴赏练习不属于这一档。

  2. V2Zhiyi · 知意独立受控测试

    从背得出延展到读得懂：位置级词义题、逐句翻译任务与独立理解记录。

    该链路与正式背诵档分开验证；参考译文、评分点和本机参考评分不构成公开 AI 判分承诺。

    • 位置级客观题：只对已审核的篇目—段落—字词锚点出题。
    • 逐段解锁：完成首次成功提取且不在重新学习状态后，才出现对应理解练习。
    • 逐句翻译：作答、参考评分与理解统计独立保存，不影响背诵记忆状态。
  3. V3Tongju · 通句后续方向

    把文言句子还原成可以解释的现代汉语。

    先做句式、语序与译文练习；任何检查都以已审核的要点为范围，不承诺通用自动判分。

    • 特殊句式识别与语序复原。
    • 译文闪卡、词块排序与关键成分配对。
    • 在审核范围内给出翻译练习反馈。
  4. V4Jianjing · 见境后续方向

    根据原文证据，练习诗文的结构、手法、情感与意象关系。

    先建立可追溯的鉴赏内容和证据选择练习；不让模型替代原文或充当唯一标准答案。

  5. V5Wenxue · 问学后续方向

    在明确范围内和 AI 进行追问、提示与学习对话。

    AI 只能基于已审核的原文证据和评分要点给反馈，不能自行定义对错；口头作答先转成文字再处理。

  6. V6Rongtong · 融通长期方向

    把背诵、词义、翻译与鉴赏串成一条个人学习路线。

    不同能力仍分别记录、分别解释；个性化不会把学习者压缩成一个分数，也不会成为不可解释的黑箱。

边界

使用前，先知道正式背诵档的范围。

课文、知识工具和背诵排程已经可用；内容复核、发行验证与云端能力仍是不同阶段的事情，不会混在一段话里。

当前可用

  • 148 篇课文的浏览与阅读入口，以及分段“译与赏”和全文赏析。
  • 1,152 条实词/虚词、29 条基础句式的只读浏览工具。
  • 逐字背诵、记忆支点、FSRS 复习队列、学习计划、预测与撤销。

正在完善

  • 课文正文、句读、注释和读音按篇复核；可浏览不等于已通过教材审定。
  • 下一轮安装包的签名、跨平台构建和真实设备验证；最新范围以下载页和 Release 为准。

暂未提供

  • 账号、云同步、自动备份和跨设备接力；重要记录请自行备份。
  • 自动更新、语音识别、AI 对话与通用自动判分。
  • 知意理解答题与逐句翻译；它们只在独立测试档内验证。
