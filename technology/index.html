技术披露

15 条计算链，逐条说清它们决定了什么。

从一次背诵动作，到下一次复习、今天的队列和计划预测，Lnk Lumen 把会实际影响学习决策、预测或反馈的独立计算链公开在这里。动画、页面筛选和普通排序不计入。

证据边界

研究提供原则，产品公开自己的推断。

我们不把“用了算法”当作科学结论。主动提取、间隔安排与反馈设计有独立研究依据； FSRS 是公开可审查的记忆模型；行为评分、优先级、预测和支点则是 Lnk Lumen 的工程策略，仍需由真实使用继续检验。

研究依据

把答案移出视线，再安排下一次提取。

重复提取、间隔安排与反馈如何影响长期保持，是我们设计练习循环的出发点，而不是用来为所有产品细节背书。

诚实表达

计划投影不是成绩单。

“今日约几分钟”是当天实际入队项目的预估；“还需几小时”和“预计掌握度”是覆盖多轮练习的规划模拟。

核心数据流

每一步都能追到它的输入与下一步。

数据默认留在当前设备。复习日志保存状态前后快照与原因；撤销恢复的是上一份状态，而不是重新计算一个更好看的结果。

  1. 背诵动作
  2. 行为评分、弱字符与有效时长
  3. FSRS 更新段落记忆状态
  4. 优先级与每日队列
  5. 今日任务、计划预测与时间线
第一层 · 把一次背诵拆成信号

不是给你一个总分，而是保留它为什么发生。

这一层不直接宣称“记住了多少”。它记录错误、提示、停顿、撤销、输入对齐和有效时长，让后面的模型可以各取所需，而不是把不同含义揉成一个分数。

01

行为评分推断

产品规则 · 可审查
输入
错字、提示、撤销、首次响应时间、整段耗时与个人速度基线。
计算
错字会建议 Again；提示、撤销或明显过慢会建议 Hard；没有提示且明显快会建议 Easy；其余建议 Good。建议评分会和理由一起写入日志。
输出
一条供 FSRS 使用的 1–4 级评分建议，而不是直接替用户宣告掌握度。

边界：这是一套工程映射，不是某篇论文直接给出的评分规则；规则与阈值可以被复查和调整。

02

薄弱字符 EWMA

工程诊断 · 可解释
输入
每个字的错误、提示、停顿与撤销事件。
计算
先按 0.45 / 0.25 / 0.20 / 0.10 合成当次弱度，再以 α = 0.30 的指数加权移动平均更新：新信号占三成，历史状态占七成。
输出
字级弱度，用于诊断、支点回避和队列排序。

边界：它不直接修改 FSRS 的记忆状态，避免一次卡顿被放大成整段“不会”。

03

输入法模糊匹配

交互容错 · 非记忆模型
输入
用户输入与原文，均转为带声调数字的拼音序列。
计算
动态规划对齐逐字比较；完全同音、同声母或同韵母得到不同相似度，插入、删除和替换也有不同代价。严格前缀与宽松前缀分别判断。
输出
精确、近似、局部、未确定等匹配状态，以及具体字位。

边界：近音只是一种输入辅助，不等于内容正确；低于阈值不会被无条件放行。

04

拼音生成与人工覆盖

数据处理 · 人工优先
输入
整句原文与逐字人工读音标注。
计算
先使用整句上下文生成拼音，再以人工标注覆盖特定字音、古音或破读。
输出
用于首次朗读和输入对齐的逐字拼音。

边界：自动生成不是审校；人工覆盖表的覆盖范围会单独披露，不能把未校读音称为权威标注。

第二层 · 让反馈回到下一次复习

模型安排下一次出现，不替你学习。

主动提取、间隔安排与反馈设计是这一层的研究基础。Lnk Lumen 使用 FSRS 维护段落级记忆状态，再把字级信号留给诊断与排序。两者不混为一个“智能分数”。

05

FSRS 记忆调度

开源记忆模型 · DSR
输入
评分、复习次数、遗忘次数、上一次状态与复习时点。
计算
用难度（Difficulty）、稳定性（Stability）和可提取率（Retrievability）描述一个段落；一次复习更新状态，再推算下一次到期时间。
输出
当前可提取率、下一次复习时间、记忆状态与可回放的引擎日志。

边界：FSRS 估计的是模型内的回忆机会，不是考试分数，更不是对人的能力评价。

06

短期再插队

队列规则 · 有上限
输入
一项复习后的 FSRS 状态与预计到期时点。
计算
若仍处于 learning 或 relearning，项目会在预计到期时重新进入当前队列；同一轮最多再插回两次。
输出
让刚卡住的内容在同一轮里再次获得提取机会。

边界：它不是无限重试；上限存在是为了避免一项内容吞掉整天的练习预算。

07

支点选择与渐退

产品假设 · 确定性算法
输入
分句边界、复习次数、支点密度、段落内容与固定种子。
计算
按分句均摊候选字，避开相邻字；相邻两次接触互斥。支点比例依次从 30% 降到 20%、12%、6%，最后归零。
输出
少量会轮换、会撤走的记忆支点。

边界：脚手架逐渐撤离是产品设计假设，不把它表述为已被本产品数据证明的教学结论。

第三层 · 决定今天先做什么

优先级写在明处，日负荷也有硬边界。

到期复习先于新内容；新内容仍按计划、教材与原文段落顺序进入队列。优先级只用于可解释的取舍，不应绕过已到期的复习。

08

任务优先级

产品排程 · 权重公开
输入
可提取率、逾期程度、字级弱度、目标日期压力与重要性。
计算
分数由 memory urgency 0.50、overdue 0.15、weakness 0.15、deadline 0.10、importance 0.10 加权；所有分量都限制在 0–1。
输出
到期任务之间的可解释排序与排入理由。

边界：权重代表当前产品取舍，不是科学上唯一正确的配方；版本会随实现统一更新。

09

动态新内容基准线

负荷控制 · 保守投放
输入
用户基准线、每日上限、到期复习压力、剩余新内容、截止日期、单项估时和学习强度。
计算
先计算复习占用与新内容容量，再在正常基准、截止日需求和可承受上限之间取值；复习压力高时自动收缩。
输出
今天新内容的目标数量及原因。

边界：每日上限是可投入的最大值，不承诺每天都必须排满。

10

每日任务装箱与顺序

队列构建 · 预算约束
输入
到期状态、优先级、原文位置、学习计划和每日秒数预算。
计算
先排到期与短期巩固，再排新内容；新内容保持计划、教材和原文段落顺序，并按每项预计秒数装入当天预算。
输出
今日队列、每一项被排入的理由和预计时长。

边界：“今日约几分钟”是实际入队项目的预计秒数之和，和目标日前的累计投入不是同一个数字。

第四层 · 预测投入，不伪造确定性

先说明估计来自哪里，再显示“还要多久”。

预测是规划工具，不是承诺。样本不足时系统使用篇幅、文体和多轮提取的保守初值；只有有效训练记录会逐步改变个人模型。

11

单项耗时估算与实测校正

个体化估时 · 逐步混入
输入
字数、文体、学习状态、复习次数、稳定度、遗忘、弱度与有效实测时长。
计算
新内容估时较慢；学习中会加快；稳定内容更快；遗忘或薄弱项再提高。合格实测时长按权重逐步混入原估计。
输出
单个段落的预计秒数。

边界：快捷完成、过短、过长或每字耗时异常的记录会被排除，不参与校准。

12

全计划时间预测与个人模型校准

计划模拟 · 带置信阶段
输入
新学、巩固、稳定、薄弱项数量，目标日前可用天数，以及有效训练样本。
计算
估算多轮主动提取的总时间，只用有效样本的每字耗时中位数校准；样本数、覆盖单元数和覆盖率决定“初始、建立中、校准中、已细化、精细”阶段。
输出
预计总投入区间、每日建议时长、可行性与置信阶段。

边界：样本少时区间会更粗；它是时间预算模拟，不是未来成绩的承诺。

13

推荐方案与可达掌握度上限

可行性约束 · 不鼓励过度承诺
输入
年级、篇幅、文体、段落数、截止日、每日可用时长与计划预测。
计算
先推荐每日时长与截止日期；当期限或时间预算不足时，按可投入时间与预测投入的比例收紧可选掌握度上限。
输出
可执行的计划建议与当前条件下的掌握度上限。

边界：上限是计划可行性提示，不是对学习者做能力判断。

14

时间线与篇目掌握度投影

排程模拟 · 非实时成绩
输入
计划顺序、每日预算、预计新学与复习耗时、覆盖率、练习深度与薄弱比例。
计算
把新内容按顺序分配到日期，并模拟计划内的覆盖、复习深度、薄弱占比与间隔推进。
输出
时间线里的预计掌握度与完成节奏。

边界：“预计掌握度”是排程投影，不是某次考试或当下真实记忆概率。

15

单篇详情页预测

局部解释 · 与全计划分开
输入
单篇字数、复习次数、强度、错误与该用户的有效训练记录。
计算
以该篇的学习状态估计还需的练习时长与天数，为“这一篇还要多久”提供局部解释。
输出
单篇的剩余时长、天数与状态说明。

边界：局部预测与全计划预测的参数仍在收敛中；两者不一致时，不能挑更乐观的一个当作结论。

可复查参数

把会影响决策的三个核心式子放在台面上。

这些是当前实现使用的默认权重与更新方式。它们不应被理解为一组永久不变、对每个人都最优的常数。
